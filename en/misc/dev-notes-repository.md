## Dev Notes Repository

### Structure

- Repository name - `dev-notes`
- `README` required
  - One-sentence description in English and Polish
- Main `index` required in English and Polish
- GitHub Pages title: Dev Notes
- Use [kebab-case](convention/naming.md) for all folders and files
- Content organized under:

  - `en/`
  - `pl/`
- Category folders define content areas
- Any folder may contain its own `index`

### Content

- Polish versions are optional
- Content should contain concise technical knowledge
- When using LLM-generated material, reduce it to the essential technical information
- Prefer minimum words with maximum information density

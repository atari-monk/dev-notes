## Install CLI

Install python cli globally (ubuntu).

### Install pipx (once)

```sh
sudo apt install pipx
pipx ensurepath
```

### Install CLI with pipx

#### Deactivate virtual environment

```sh
deactivate
```

#### Uninstall CLI

```sh
pipx uninstall cli-name
```

#### Install CLI

```sh
pipx install -e .
```
